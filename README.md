# Professional and Personal Projects:

### Nebu Ledger — Personal Finance Tracker (just started, work in progress)

A personal finance tracking application focused on **simplicity**, **data ownership** with **multi-currency support**, **group expense management**, and seamless usage across devices via **PWA**.

The product is designed for scenarios where users need to track shared and individual finances: travel groups, couples, roommates, and small teams. It supports flexible splitting of expenses, shared budgets, and consolidated analytics across multiple participants.

Frontend is built with **React** (TypeScript), with a mobile-first PWA experience.  
Backend is implemented in **Go**, providing APIs for authentication, financial data management, multi-user collaboration, and synchronization.

Core focus areas include multi-currency accounting, real-time group collaboration, and a smooth installable web-app experience.
`React` `TypeScript` `Go` `PWA` `Multi-currency` `Group expenses`
